1 · Creating vectors

      
    
        
  • c(...) – combine values: income, food, …
    • 
        
  • rep(15000, 12) – repeat a value; rep(1:4, each = 3) – repeat each.
    • 
        
  • month.abb – a built-in character vector.
    • 
        
  • A vector holds one type only: numeric, character or logical.
    • 
      

    
2 · Naming elements

      
    
        
  • names(income) <- months lets you write savings["Dec"].
    • 
        
  • Names are carried through arithmetic, so savings is named too.
    • 
      

    
3 · Vectorised arithmetic

      
    
        
  • rent + food + … adds all 12 months at once — no loop needed.
    • 
        
  • savings / income * 100 works element by element.
    • 
        
  • Recycling: savings / 1000 reuses the single number 1000 for every element.
    • 
      

    
4 · Indexing

      
    
        
  • By position: savings[1:3], savings[c(6, 7)]
    • 
        
  • Negative: savings[-1] drops January.
    • 
        
  • By name: savings["Dec"]
    • 
        
  • Helpers: head(), tail().
    • 
      

    
5 · Logical filtering

      
    
        
  • savings < 0 gives a TRUE/FALSE vector.
    • 
        
  • months[savings < 0] keeps months where it is TRUE.
    • 
        
  • any(), all(), sum(logical) to count.
    • 
        
  • %in% tests membership: months %in% festive.
    • 
        
  • ifelse() builds the status vector in one line.
    • 
      

    
6 · Built-in vector functions

      
    
        
  • sum, mean, median, range, max, min
    • 
        
  • which.max, which.min – position of best / worst
    • 
        
  • cumsum (running total), diff (change from previous)
    • 
        
  • sort, rev, tapply (group totals)
    • 
      

    
Ideas to extend the project

    • 
        
  • Use seq(1000, 12000, by = 1000) to simulate a monthly savings plan.
    •

Run the project in R

    
    
      
  1. Install R (and optionally RStudio) from cran.r-project.org.
    2. 
      
  2. Open the R Code tab and click Download finance_tracker.R (or copy the code into a new script in RStudio).
    3. 
      
  3. In RStudio press Source, or from a terminal run: Rscript finance_tracker.R
    4. 
      
  4. Change savings_target_pct and monthly_budget at the top of the script and run again — compare with the console panel on the dashboard using the same values.
    5. 
      
  5. In the R console, type a vector name (e.g. savings) after sourcing the script to inspect it directly.
    6. 
    

    
Note: this dashboard re-implements the same logic in JavaScript so it can run live in a browser. The R script is the actual project; the dashboard is its visual front end.
